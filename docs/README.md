# Frontend docs

The marketing/account Next.js app lives here.

**API, Prisma, and Neon** live in sibling folder [`../nela-backend`](../nela-backend).

- Set `NEXT_PUBLIC_API_URL` to the running API (local default `http://localhost:3001`).
- Shared DTOs: `@nela/shared` from `nela-backend/packages/shared`.
