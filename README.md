# NELA Webpage

Next.js marketing + account UI. **API / Prisma / Neon live in sibling [`../nela-backend`](../nela-backend).**

## Run locally

1. Start the API in `nela-backend` (`npm install` → `npm run db:push` → `npm run dev`)
2. Here: copy `.env.example` → `.env` (set `NEXT_PUBLIC_API_URL`)
3. `npm install` then `npm run dev` → [http://localhost:3000](http://localhost:3000)

Shared DTOs come from `@nela/shared` (`file:../nela-backend/packages/shared`).
